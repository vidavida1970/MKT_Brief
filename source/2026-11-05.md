# Addit Daily Marketing Brief · 2026-11-05

## 한 줄 결론

**AI를 더 많이 쓸수록, 보안·비용·대체 경로를 함께 설계해야 한다.** 오늘의 원문은 Claude Code 침해와 ChatGPT 장애가 의존성의 위험을 보여주는 동시에, Revolut의 비용 절감과 Heimstaden의 업무 혁신처럼 AI를 계속 쓰기 위한 운영 조건도 함께 제시한다.

## 오늘의 5대 트렌드

1. Claude Code VS Code 확장 2.1.313에서 SSH 백도어가 발견됐다는 보도가 나와 즉시 버전 점검이 필요하다.
2. Revolut는 Claude Code에서 중국 Z.ai의 GLM으로 전환해 코딩 AI 비용을 약 90% 낮췄다고 밝혔다.
3. ChatGPT 검색 유사 질문량은 구글의 20% 수준까지 접근했고, 서비스 장애는 단일 도구 의존의 취약성을 드러냈다.
4. 현대차 사용 제한 보도와 구글 학교 정책 논란은 조직별 승인·보안·대체 경로 설계가 필요하다는 점을 보여준다.
5. Gemini TTS 리믹스·로보틱스·Snowflake 연결처럼 AI는 텍스트 도구에서 음성·현장·데이터 시스템으로 확장된다.

## CASE STUDY

### 1. ChatGPT Search — 검색 유사 질문량이 구글의 20%까지 접근

- 지역: KR
- 원문: https://www.chosun.com/economy/tech_it/2026/11/04/JWVB6NRKBFHKXAEO2UUBTASYJI/
- 이미지: https://www.chosun.com/resizer/v2/MQ4WEMBWGM2DOMTCGJQTGYRZMQ.jpg?auth=2eb7e8a24f4a25f64c767698f1fe569b30f0f74665882cc12bdc25ffe43b64bc&width=1200&height=630&smart=true
- 확인 사실: 조선일보는 오픈AI 발표를 인용해 ChatGPT의 검색 유사 질문량이 구글 검색량의 20%에 달했다고 보도했다. 음성 기능의 주간 이용자 2억5천만 명도 함께 언급되며, 챗봇이 정보 탐색과 계획 수립 접점으로 확장되는 흐름을 보여준다.
- Addit Insight: 브랜드는 검색 결과뿐 아니라 AI가 답변을 구성할 때 인용할 수 있는 정보 구조를 함께 관리해야 한다.

### 2. ChatGPT 장애 — 업무 도구의 편리함이 단일 의존으로 바뀌는 순간

- 지역: KR
- 원문: https://www.hankyung.com/article/202611044353g
- 이미지: https://img.hankyung.com/photo/202611/01.46301716.1.jpg
- 확인 사실: 한국경제는 ChatGPT 장애 당시 직장인들이 업무를 진행하지 못해 혼란을 겪었다고 보도했다. 같은 기사에서 클로드 이용자가 1년 새 853% 증가했다는 와이즈앱 조사도 소개하며, 사용자가 대체 도구를 찾는 움직임을 전했다.
- Addit Insight: AI 업무화의 다음 단계는 가장 잘하는 도구가 아니라 장애 때 바로 전환할 수 있는 백업 흐름을 만드는 것이다.

### 3. 동의대 × Google Korea — 대학생 실무역량을 키우는 Gemini Academy

- 지역: KR
- 원문: https://www.kookje.co.kr/news2011/asp/newsbody.asp?code=0300&key=20261104.99099001299
- 이미지: https://db.kookje.co.kr/news2000/photo/2026/1104/L20261104.99099001299i1.jpg?18
- 확인 사실: 국제신문은 동의대가 고용노동부·구글코리아와 함께 ‘제미나이 아카데미’를 개최했다고 보도했다. 대학생이 생성형 AI를 실제 학습과 업무에 활용하는 교육 접점을 만든 사례다.
- Addit Insight: 도입 확산은 라이선스 배포보다 실제 과제·교육·피드백이 연결된 사용 장면을 설계할 때 빨라진다.

### 4. 판사들을 위한 AI — 2,600명이 13만 건을 질문한 법률 보조 실험

- 지역: KR
- 원문: https://www.youtube.com/watch?v=EoIJFGjDpOQ
- 이미지: https://i.ytimg.com/vi/EoIJFGjDpOQ/maxresdefault.jpg
- 확인 사실: MBN 뉴스7 영상은 ‘판사들을 위한 AI’를 주제로 2,600명이 13만 건을 질문한 사례를 다룬다. 법률·사법 영역에서 생성형 AI의 사용량과 검수 책임이 함께 커지는 장면이다.
- Addit Insight: 전문 영역에서는 질문량보다 답변의 근거, 검수자, 책임소재가 서비스 설계의 핵심이다.
