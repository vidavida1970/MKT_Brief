# AI 뉴스 브리핑 | 2026-11-16

## 편집 테마

**AI에 권한을 줄수록, 검수와 공급망이 중요하다**

오늘은 AI가 시험장, 사내 업무, 쇼핑, 개인 비서, 개발 도구로 들어가며 ‘답변’에서 ‘실행’으로 이동한 사례가 한꺼번에 드러난 날이다. 그만큼 인증정보·협력사 키·앱 연결·사람의 승인선이 실제 성과와 위험을 가르는 운영 조건이 됐다.

## 오늘의 5대 시그널

1. 세무사 시험 수석 합격자가 초소형 카메라로 문제를 촬영하고 AI로 답을 확인한 부정행위를 자백하며 자격검정의 기기·검수 체계 재설계를 촉발했다.
2. Cursor는 Fireworks에 발급한 접근 키 노출이 내부 시스템 침입과 악성 Claude Code 확장 배포로 이어졌다고 공개했다.
3. Anthropic은 Claude Fable 5.2의 1,000개 에이전트가 Lean으로 페르마의 마지막 정리를 30시간에 형식화했다고 발표했다.
4. SKT AX 챌린지는 AI가 자료 수집·반복 처리를 맡고 판단·결정·승인은 사람이 맡는 분업 구조를 현장형으로 보여줬다.
5. 현대백화점의 더현대 하이와 GPT 기반 AI 비서 닷츠는 AI 고객 접점이 추천을 넘어 거래·실행 권한으로 확장되고 있음을 보여준다.

## CASE STUDY

### 01 · KR — 세무사 시험 AI 부정행위 자수

- 원문: https://www.joongang.co.kr/article/25478753
- 보완 원문: https://www.joongang.co.kr/article/25478754
- 이미지: https://pds.joongang.co.kr/news/FbMetaImage/202611/8e08433d-9e0e-4a33-ab64-6b7b4ec872eb.jpg
- 확인된 사실 1: 제63회 세무사 시험 수석 합격자가 초소형 카메라로 문제를 촬영하고 AI로 전송해 스마트폰으로 답을 확인했다고 자백했다.
- 확인된 사실 2: 한국산업인력공단은 해당 합격자에 대한 고소와 합격 취소 절차, 국가자격시험 전반의 전수조사와 재발 방지 대책을 추진한다고 밝혔다.
- Addit Insight: AI 부정행위는 모델 차단만으로 해결되지 않으며, 기기 반입·전파·감독·사후 검증을 묶은 다층 검수 체계가 필요하다.

### 02 · KR — SKT AX 챌린지

- 원문: https://www.ddaily.co.kr/m/page/view/2026111501482054711
- 이미지: https://www.ddaily.co.kr/photos/2026/11/15/2026111501532599316_l.jpg
- 확인된 사실 1: SK텔레콤은 AI 에이전트가 구성된 가상 사내 환경에서 자료 수집·정리·반복 처리를 수행하고, 참가자가 업무 시스템을 연결해 미션을 해결하는 AX 챌린지를 진행했다.
- 확인된 사실 2: 판단·결정·승인은 사람이 담당하고, AI가 읽은 메일·메신저·신청 서류를 바탕으로 배치안과 업무 결과를 제안하는 방식으로 역할을 나눴다.
- Addit Insight: 업무 자동화의 출발점은 “AI가 무엇을 할까”가 아니라 “사람이 끝까지 책임질 판단은 무엇인가”를 먼저 정하는 일이다.

### 03 · KR — 더현대 하이, 앱스 인 챗GPT 입점

- 원문: https://www.newsis.com/view/NISX20261115_0003868534
- 이미지: https://img1.newsis.com/2026/11/15/NISI20261115_0002292220_web.jpg
- 확인된 사실 1: 현대백화점은 오픈AI의 앱스 인 챗GPT에 프리미엄 큐레이션몰 더현대 하이 전용 쇼핑 서비스를 선보였다.
- 확인된 사실 2: 챗GPT에서 상품을 추천받은 뒤 더현대 하이로 이동해 상품 확인·구매·결제·예약까지 이어지며, 오프라인 팝업과 외식 정보도 안내한다.
- Addit Insight: AI 검색 노출을 넘어 구매까지 연결하려면 상품 피드·재고·가격·예약 정책을 정본 데이터로 관리해야 한다.

### 04 · KR — GPT 기반 AI 비서 닷츠

- 원문: https://www.yna.co.kr/view/AKR20261114013700091
- 이미지: https://img4.yna.co.kr/photo/etc/gt/2026/09/30/PGT20260930065801009_P4.jpg
- 확인된 사실 1: 연합뉴스는 GPT 기반 AI 비서 닷츠를 한 달 사용한 경험을 통해 이메일·일정 등 개인 업무 데이터와 에이전트 권한의 관계를 다뤘다.
- 확인된 사실 2: 에이전트가 유용해질수록 사용자는 더 많은 권한과 데이터를 주고 싶어 하지만, 권한 범위를 넓히는 만큼 실행 전 확인·철회·기록 기능이 중요해진다.
- Addit Insight: 개인 비서는 기능 목록보다 읽기·쓰기·전송 권한을 단계별로 나누고, 사용자가 언제든 회수할 수 있게 만드는 것이 핵심이다.

### 05 · GLOBAL — Cursor 보안 사고와 악성 Claude Code 확장

- 원문: https://cursor.com/blog/security-incident-update
- 사용자 제공 관련 보도: https://www.hitech.co.kr/news/articleView.html?idxno=62940
- 이미지: https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/og/opengraph-default.png
- 확인된 사실 1: Cursor는 Fireworks에 발급한 접근 키가 노출된 뒤 읽기 전용 저장소의 코딩 에이전트 기록과 일부 내부 SaaS 자료에 대한 접근이 이어졌다고 밝혔다.
- 확인된 사실 2: 탈취 자격 증명으로 Cursor VS Code 마켓플레이스 캐시에 악성 Claude Code 확장이 약 11시간 배포됐고, 특정 버전을 요청한 최대 5,000명이 영향을 받았을 가능성이 있다고 설명했다.
- Addit Insight: AI 공급망은 모델만 검수하는 대상이 아니다. 외부 추론사·저장소·마켓플레이스·확장·자격 증명까지 연결 경로 전체를 지속 점검해야 한다.
